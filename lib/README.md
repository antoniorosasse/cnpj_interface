# lib/

Esta pasta guarda o driver JDBC do IBM i (AS/400).

## jt400.jar

O arquivo `jt400.jar` **nao esta versionado** neste repositorio
(ele tem ~6 MB e e propriedade da IBM).

Para baixar:

1. Acesse https://jt400.sourceforge.net/
2. Baixe o arquivo `jt400.jar` (versao mais recente)
3. Coloque exatamente nesta pasta: `lib/jt400.jar`
